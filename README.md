## 📌 Project Overview

This repository contains the source code for my personal web portfolio, an interactive showcase designed to present my work across cloud systems, software development, and network infrastructure.

Rather than relying on templates or visual clutter, the portfolio was custom-built from the ground up with a strict monochromatic, minimalist aesthetic. The goal is to deliver a fast, responsive, and distraction-free experience that lets the engineering case studies, system architectures, and technical documentation speak for themselves.

---

## 🎯 What the Portfolio Showcases

- **Project Consoles:** Breakdown of my builds including cloud-based AI pipelines, enterprise software backends, and multi-VLAN Cisco networking topologies.
- **Skills & Technical Proficiency:** Categorized directory of technical competencies spanning cloud platforms, programming languages, operating systems, and network engineering tools.
- **Verified Credentials & Certifications:** Direct verification links and credential details for industry certifications and ongoing specializations.
- **Experience & Academic Background:** Structured timelines detailing professional internship work, software testing, and information technology degree coursework.

---

## ⚡ User Experience & Interface Highlights

- **Physics-Driven Interactions:** Smooth, spring-based animations powered by Framer Motion, paired with a custom magnetic cursor that smoothly binds to buttons, pills, and navigation elements.
- **Interactive 3D Centerpiece:** A lightweight Three.js canvas integrated directly into the landing section to create dynamic depth while maintaining high frame rates.
- **Scroll-Aware Dynamics:** Fluid transitions and scroll-driven reveals that guide the reader naturally through each section without abrupt snapping.
- **Responsive & Accessible Design:** Fully optimized layout across mobile, tablet, and desktop screens with clean typographic hierarchy.

---

## 🛠️ Built With

- **Framework:** Next.js 15 (App Router)
- **Library & Language:** React 19, TypeScript
- **Styling:** Tailwind CSS (Strict Monochromatic Design Tokens)
- **Animation & Motion:** Framer Motion 12
- **3D Graphics:** Three.js
- **Icons:** Lucide React & Custom SVG Wrappers
- **Deployment & Analytics:** Vercel Edge Network, Speed Insights, Core Web Vitals
