## Executive Overview

Legacy perimeter defense models fail when microservices cross hybrid clusters and developers require granular multi-tenant isolation. This architecture established a comprehensive **Zero-Trust Network Architecture (ZTNA)** for over 140,000 ephemeral container workloads.

Every pod identity is verified at the hardware kernel level using **SPIFFE/SPIRE Workload Attestation**, dynamic short-lived X.509 SVID certificates, and strict eBPF-enforced behavioral runtime security using **Cilium Tetragon**.

## Core Security Controls

### 1. Cryptographic Workload Identity (SPIFFE)
Workloads never store long-lived credentials. SPIRE agents validate container cgroups and Linux UID/GID before providing cryptographic SVID tokens via a local Unix domain socket.

### 2. Runtime Threat Mitigation with Tetragon
Tetragon monitors low-level kernel events (`sys_execve`, `sys_socket`, namespace escapes) in real-time. Unauthorized binary executions within production namespaces trigger automatic process termination inside the kernel before data exfiltration can occur.

```yaml
apiVersion: cilium.io/v1alpha1
kind: TracingPolicy
metadata:
  name: block-privilege-escalation
spec:
  kprobes:
    - call: "sys_execve"
      syscall: true
      args:
        - index: 0
          type: "string"
      selectors:
        - matchArgs:
            - index: 0
              operator: "Prefix"
              values:
                - "/bin/bash"
                - "/bin/sh"
          matchNamespaces:
            - "production-critical"
          matchActions:
            - action: Sigkill
```
