## Executive Overview

Cloud infrastructure sprawl and out-of-band manual changes ("clickops") degrade operational stability and inflate infrastructure bills. This project introduced an autonomous closed-loop reconciliation platform combining **Terraform state graph analysis**, **n8n automated event workflows**, and a high-performance **Golang drift detector**.

The system actively audits 4,200+ managed cloud resources across GCP and AWS, remediating unmanaged configuration drift within seconds while continuously rightsizing compute instances based on live utilization heuristics.

```
└──────────────────────────────────────────────┘
         │                          │
         ▼ (No Drift)               ▼ (Drift Detected)
    [Audit OK]               [Auto-Remediate Run]
                                    │
                                    ▼
                         [GitOps Commit / Slack Alert]
```

## Key Capabilities

1. **Automated Drift Rollback**: If an engineer manually exposes a security group or alters an IAM binding in the cloud console, the drift worker detects the delta within 6 seconds and restores the GitOps state.
2. **FinOps Dynamic Rightsizing**: Machine learning models evaluate 14-day P99 CPU/RAM consumption, dynamically swapping idle compute nodes with spot ARM64 instances during off-peak windows.
3. **Audit Trail**: Every drift event and reconciliation cycle is logged into a queryable Supabase PostgreSQL database for forensic traceability.

## Measurable Results

- **Cost Efficiency**: Realized a verified **38.4% reduction** in recurring cloud compute expenses within 90 days.
- **Drift Resolution Time**: Reduced mean-time-to-remediate (MTTR) configuration drift from **3.4 days** to **under 15 seconds**.
- **Developer Velocity**: Eliminates manual troubleshooting of divergent staging and production environments.
